# P3 会话层 + MCP 调试工具面 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 `DotNetDebugger.Session` 库实现会话层（多调试会话管理 + 停点事件缓冲/查询 + agent 轨迹日志），并在宿主 `DotNetDebuggerMcp` 暴露 `debug_*` 系列 MCP 工具（launch/attach/disconnect/breakpoint/continue/step/state/stack/threads/variables/exceptions），让 agent 能经 stdio 完整走通「启动/附加 → 定位断点 → 运行 → 命中 → 观察 → 单步」的调试闭环。

**Architecture:** Session 库依赖 Engine（已有 `DebugSession` 能力）+ Decompiler（用于断点定位辅助与反编译展示）；提供 `DebugSessionManager`（v1 单活动会话）持有活动 `DebugSession`，缓冲其 `DebugEvent` 流为可查询状态（当前是否停、最近停点、线程/栈/变量缓存），并记录 `AgentAction` 轨迹（供 P4 Web 回放）。宿主 MCP 工具经 Session 层路由——控制工具（continue/step 等）**异步返回**（带默认超时参数），停点信息由 `debug_state`/`debug_stack`/`debug_variables` **查询**（用户拍板：异步工具带默认超时 + 断点查询工具）。

**Tech Stack:** .NET 10 / C# / ModelContextProtocol 2.2.0 / DotNetDebugger.Engine（P2）/ DotNetDebugger.Decompiler（反编译辅助）/ xunit.v3

**Spec:** `docs/planning/specs/2026-09-05-overview-design.md`（§4.3 Session 层 + §4.5 MCP 工具面 + §5 线程模型 + §7 P3）+ `decisions.md` D7/D8/D11 + 反编译工具既有模式（宿主 Tools/ 模板）

## Global Constraints

- 命名：`debug_*` 统一前缀（用户拍板）；MCP 工具前缀由注册名决定（`dotnetdebugger_debug_*`）
- Session 库独立（D8）：`src/DotNetDebugger.Session/` → `DotNetDebugger.Session`；依赖 Engine + Decompiler；宿主引 Session
- **异步工具带默认超时实际参数**（用户拍板）：控制工具（launch/attach/continue/step 等）有 `timeoutSeconds` 参数（默认如 30），返回「已启动/已继续」不等停；停点信息经 `debug_state`/`debug_stack`/`debug_variables`/`debug_threads` 查询
- **stdout 纯净纪律不可破**：宿主 stdout 只走 MCP 协议；调试工具日志走 stderr；并发回归护栏延续（MCP 会话并发下不得撕帧——调试会话管理须线程安全）
- MCP 工具参数全带默认值（空串等，AGENTS 铁律）；`[Description]` 中文、面向 agent、注明默认值；工具方法 `CancellationToken cancellationToken = default` 在末尾
- Session 库不反引用宿主/Tools；Engine 保持纯底层（Session 层封装为 agent 友好的查询/命令面）
- 依赖：Session 库引 Engine + Decompiler（复用 MetadataNaming 定位方法 token/反编译展示）
- 测试：Session 库单测（管理器状态机/事件缓冲）+ 宿主 MCP 工具集成测试（真实 DebugTarget 进程，串行）+ 既有 425 反编译测试不回归
- 每个 Task 结束提交；提交信息用中文

## 目标文件结构

```
src/DotNetDebugger.Session/
  DotNetDebugger.Session.csproj      # 引 Engine + Decompiler
  Models/
    DebugSessionInfo.cs              # 会话摘要（id/状态/目标/最近停点）
    StopContext.cs                   # 停点现场（reason/threadId/topFrame/时间）
    AgentActionLog.cs                # agent 轨迹记录（工具/参数摘要/结果/关联事件）
  DebugSessionManager.cs             # 多会话管理（v1 单活动）：CreateSession/GetActive/Close
  SessionEventBuffer.cs              # 消费 DebugEvent 流 → 当前状态（running/stopped/停点缓存）
src/DotNetDebuggerMcp/
  Tools/Debug/
    DebugSessionTool.cs              # debug_launch/debug_attach/debug_disconnect/debug_state
    DebugControlTool.cs              # debug_continue/debug_step/debug_pause
    DebugBreakpointTool.cs           # debug_breakpoint（set/remove/clear 子命令或独立）
    DebugInspectTool.cs              # debug_stack/debug_threads/debug_variables
    DebugExceptionTool.cs            # debug_exceptions（设/清异常断点）
  Services/DebugSessionService.cs    # 宿主侧会话服务（挂 AppServices 或独立单例）
tests/DotNetDebugger.Session.Tests/  # Session 库单测
tests/DotNetDebuggerMcp.Tests/       # 宿主 MCP 调试工具集成测试（新增）
```

> 注：具体工具方法粒度（launch/attach 独立 or debug_session 子命令）在 Task 3 定稿时按「agent 友好 + 参数全默认」原则展开；每工具带 timeoutSeconds 默认参数。
