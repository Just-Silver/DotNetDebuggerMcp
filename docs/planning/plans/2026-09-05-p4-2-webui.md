# P4-2 WebUI（Blazor Server + BootstrapBlazor + Monaco + 宿主 --web）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现 `DotNetDebugger.Web` Blazor Server 展示面——代码视图（Monaco 互操作，消费 P4-1 DocumentService 语句级映射）+ 状态/栈/变量/线程面板 + 最小控制（continue/step），宿主 `--web` 双模式承载（MCP 常驻同时起 Kestrel / 纯 Web 人工调试）。

**Architecture:** Web 库改 RCL（`Microsoft.NET.Sdk.Web` + net10 + BootstrapBlazor 10.*），页面组件消费宿主经 `WebHostBootstrap.Configure(manager)` 注入的 `DebugSessionManager`（spec §9.1 显式注入，Web 不反引宿主）。代码视图 = 自研 Monaco 互操作（参考本地 `DebuggerExternals\BlazorMonaco`：`wwwroot/jsInterop.js` 桥 + `min/vs` 静态资产 + `deltaDecorations`/`revealLineInCenter`）。刷新 = 轮询 SessionEventBuffer 快照（spec §5 优先）。宿主 `--web` 分支双 host 并联 + Web 日志走 stderr（spec §9.1）。

**Tech Stack:** .NET 10 / Blazor Server（InteractiveServer）/ BootstrapBlazor 10.*（模板 `bbapp` 参考：`AddBootstrapBlazor()` + `MapRazorComponents<App>().AddInteractiveServerRenderMode()`）/ monaco-editor 0.55.1 min 资产（npm pack 静态拷入 wwwroot）/ DocumentService（P4-1）

**Spec:** `docs/planning/specs/2026-09-05-p4-webui.md`（§4 页面/§5 数据流/§6 文档模型/§9.1 宿主侧 + §9.2 Web 库侧）+ BB 模板样板（`dotnet new bbapp` 已确证装配形态）

## Global Constraints

- **依赖方向**：McpHost → Web → Session + Decompiler；Web 只 `using DotNetDebugger.Session`/`DotNetDebugger.Decompiler.*`，**不反引宿主**（spec §9.1）。
- **Session 注入**：宿主 `WebHostBootstrap.Configure(DebugSessionManager manager)` 静态方法传 `DebugSessionService.Manager`；Web 内静态/DI 持有。Manager 是 `IAsyncDisposable`——进程退出 Dispose 一次（宿主收尾或 Web ApplicationStopping）。
- **stdout 纪律（关键）**：宿主 stdout 只走 MCP 协议。Web host 日志**必须显式重配** `ClearProviders()` + `AddConsole(LogToStandardErrorThreshold=Trace)`（Web host 不继承 MCP builder 配置，默认 Console 写 stdout 会撕帧）。回归护栏：MCP 模式 Web 开着跑 McpSessionConcurrencyTests。
- **双 host 生命周期**：Web host 与 MCP host 共享 CancellationToken 联动（任一侧停整体退）；MCP host `RunAsync` 阻塞为主，Web host `RunAsync` 并行。
- **Monaco 互操作自研最小桥**：只实现 create/setValue/deltaDecorations/revealLineInCenter/dispose 五方法（spec §9.2），参考 BlazorMonaco jsInterop.js 结构但不大而全。**禁止引 BlazorMonaco 包**（两套 monaco 全局冲突，spec §9.2）。
- **RCL 承载**：Web 库组件不在启动程序集 → 宿主装配 `AddRazorComponents().AddInteractiveServerComponents()` + `MapRazorComponents<App>().AddInteractiveServerRenderMode()` + `AddAdditionalAssemblies(typeof(Web 程序集).Assembly)`（spec §9.1）。
- **代码视图数据**：DocumentService（P4-1）`GetTypeDocument` 产干净文本+映射，`GetLineForIlOffset` 停点定位、`GetIlStartForLine` 反向设断点。映射无 PDB 即可语句级（P4-1 实测）。
- **面板数据**：SessionEventBuffer（CurrentState/LastStop/StoppedThreadId）+ Engine DebugSession（GetStackFrames/GetVariables/GetThreads）只读快照。
- 测试：`tests/DotNetDebugger.Web.Tests/` 覆盖**纯服务端可测部分**（状态读取/映射消费/服务），浏览器交互人工验证（spec §8）。宿主 427 + Decompiler 12 + Engine 6 + Session 5 全量不回归。
- 外部参考：Monaco 互操作抄 `E:\Code\Projects\Externals\DebuggerExternals\BlazorMonaco`（jsInterop.js 桥面/StandaloneCodeEditor 生命周期/资产布局）；装配抄 `dotnet new bbapp` 样板。README/CHANGELOG/握手简介同步纪律沿用。

- [ ] **Step 2: WebHostBootstrap（装配入口，spec §9.1）**

`WebHostBootstrap.cs`:
```csharp
namespace DotNetDebugger.Web;

/// <summary>
/// 宿主 → Web 装配入口：宿主调 Configure 传入共享 DebugSessionManager 与端口，得 WebApplication 启动入口。
/// Web 只依赖 Session 库类型，不反引宿主（spec §9.1 显式注入）。
/// </summary>
public static class WebHostBootstrap
{
    private static DotNetDebugger.Session.DebugSessionManager? _manager;
    public static DotNetDebugger.Session.DebugSessionManager Manager => _manager
        ?? throw new InvalidOperationException("WebHostBootstrap.Configure 未调用");

    public static WebApplication Build(int port, string[] args)
    {
        var builder = WebApplication.CreateBuilder(args);
        builder.Logging.ClearProviders();
        builder.Logging.AddConsole(o => o.LogToStandardErrorThreshold = LogLevel.Trace);  // stdout 纪律
        builder.WebHost.UseUrls($"http://127.0.0.1:{port}");

        builder.Services.AddRazorComponents().AddInteractiveServerComponents()
            .AddAdditionalAssemblies(typeof(WebHostBootstrap).Assembly);
        builder.Services.AddBootstrapBlazor();

        var app = builder.Build();
        app.UseAntiforgery();
        app.MapStaticAssets();
        app.MapRazorComponents<Components.App>().AddInteractiveServerRenderMode();
        return app;
    }

    public static void Configure(DotNetDebugger.Session.DebugSessionManager manager) => _manager = manager;
}
```
> 注：Configure 与 Build 分离——宿主先 Configure(Manager) 再 Build+RunAsync。组件经 `WebHostBootstrap.Manager` 访问（服务端辅助经它读快照）。
