# P2 动态调试引擎 v1（Engine） Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 `src/DotNetDebugger.Engine/` 库实现 v1 **最小 agent 调试闭环**：launch/attach 目标 .NET 进程、按 method token + IL offset 下断点、continue、单步（into/over/out）、读线程/调用栈/局部变量、first-chance 异常断点、统一 `DebugEvent` 事件流；交付 Engine 库 + xUnit 集成测试（测试进程直接 attach 脚本生成的 DebugTarget.exe）+ 宿主 CLI `-dbg` 驱动命令。

**Architecture:** 用 `ClrDebug 0.4.2`（MIT，ICorDebug COM 的 C# 全量封装）+ `Microsoft.Diagnostics.DbgShim`（微软官方引导）在进程内实现调试引擎。引擎自持**专用 MTA 调试线程**：dbgshim 手动引导（挂起启动 → GetStartupNotificationEvent → EnumerateCLRs → CreateDebuggingInterfaceFromVersionEx → DebugActiveProcess）；`CorDebugManagedCallback` 事件委托驱动状态机；命令（断点/继续/单步/读状态）经队列串行化到调试线程，全部 ICorDebug 调用只在进程同步态（回调内）执行；事件经有界 `Channel<DebugEvent>` 对外发布。Engine 不依赖 Decompiler/Session/宿主，纯底层可替换（decisions D3/D8）。

**Tech Stack:** .NET 10 / C# / ClrDebug 0.4.2（MIT）/ Microsoft.Diagnostics.DbgShim 10.0.731102（微软）/ xunit.v3

**Spec:** `docs/planning/specs/2026-09-05-overview-design.md`（§4.1 Engine 层 + §4.2 DebugEvent + §5 线程模型 + §7 P2）+ `docs/planning/decisions.md` D3/D5/D11 + `docs/planning/research/06-clrdebug-api-reference.md`（API 逐行核对依据）

## Global Constraints

- 命名：程序集/命名空间 `DotNetDebugger.Engine`；文件放 `src/DotNetDebugger.Engine/` 下子目录，每目录一个命名空间（沿用 file-scoped 惯例）
- **依赖底线（MIT/微软）**：只允许引 `ClrDebug 0.4.2` + `Microsoft.Diagnostics.DbgShim`（+ RID 子包按需）；**禁止**引 dnSpyEx(GPL)/debug-mcp(AGPL)；ClrMD 不引（v2 旁路）
- **平台**：P2 仅 Windows 验证（ICorDebug/DbgShim 全平台可用但先 Windows）；Engine csproj 不加 `-windows` TFM（纯托管库，运行时再加载 native dbgshim）
- **线程纪律（spec §5，不可违反）**：
  - ICorDebug/DbgShim 产物**只在专用 MTA 线程**创建与使用（STA 创建直接抛异常）
  - `SetManagedHandler` 必须在 `Initialize()` 后、`DebugActiveProcess` 前调用
  - **每个回调处理完必须 `Controller.Continue(false)`**（否则进程停死）；事件 args 的 `.Continue` 属性不会自动调用
  - 断点/读栈/单步等「问目标」操作只在进程同步态（回调内）执行
  - 命令从外部线程进来必须**串行化**到调试线程队列
- **版本/三处同步纪律**：P2 不改版本号（仍 1.4.0）；不动 .mcp/server.json/CHANGELOG 的版本段（P5 统一 bump）；CHANGELOG `[Unreleased]` 可记 P2 能力
- **stdout 纯净纪律**：Engine 库本身不写 stdout；宿主 `-dbg` CLI 命令输出走 Console（CLI 模式非 MCP）；日志/错误走 stderr
- **DebugEvent 规范（spec §4.2 契约）**：事件统一 `SessionId/Sequence/UtcTimestamp/Kind/Payload`；`FrameLocation = { moduleName, methodToken(0x060…), ilOffset }` 全局唯一标识执行点
- Engine 依赖方向：`DotNetDebugger.Engine` 不依赖 Decompiler/Session/宿主；可被宿主/测试独立引用
- 测试：DebugTarget.exe 由 generate-testdata.ps1 追加生成（见 Task 2），git 忽略；Engine 测试项目建 `tests/DotNetDebugger.Engine.Tests/`（D11 决策：测试进程直接 attach）
- 每个 Task 结束提交；提交信息用中文

```csharp
namespace DotNetDebugger.Engine.Models;

/// <summary>
/// 执行点位置三元组：全局唯一标识一个执行点（spec §4.2 契约）。v1 断点定位与事件都用它，
/// 天然对接现有元数据层（methodToken 为 0x06 开头的 mdMethodDef）。
/// </summary>
public sealed record FrameLocation(string ModuleName, int MethodToken, int IlOffset)
{
    /// <summary>按元数据 token 格式渲染方法 token（0x06000005）。</summary>
    public string MethodTokenText => $"0x{MethodToken:x8}";

    public override string ToString() => $"{ModuleName}!{MethodTokenText}+0x{IlOffset:x}";
}
```

```csharp
/// <summary>调试事件种类（spec §4.2）。</summary>

    StepCompleted,
    ExceptionHit,
    ThreadsChanged,
```

- [ ] **Step 1: 在 generate-testdata.ps1 末尾（Ext dll 复制后、try 结束前）追加 DebugTarget 生成段**

```powershell
    # ---- DebugTarget.exe：P2 动态调试引擎的可执行调试目标 ----
    # 自包含可执行程序（不引用 TestSamples，避免调试时 resolver 干扰）；稳定方法/token 供断点/单步测试。
    $dbgSrc = @'
using System;
using System.Threading;

namespace DebugTarget;

public static class Program
{
    public static int Compute(int a, int b) => a + b;

    /// <summary>供 first-chance 异常断点测试：对 0 输入抛 DivideByZeroException。</summary>
    public static int ThrowIfZero(int value)
    {
        if (value == 0) throw new DivideByZeroException("value is zero");
        return 100 / value;
    }

    public static void Work(int iterations)
    {
        // 固定 IL 结构：局部变量 i 的 for 循环 —— 对 Work 设入口断点(offset 0)可稳定命中
        for (int i = 0; i < iterations; i++)
        {
            var acc = Compute(i, 1);
            Console.WriteLine($"[DebugTarget] work {i}: {acc}");
            Thread.Sleep(10);
        }
    }

    public static void Main(string[] args)
    {
        int n = args.Length > 0 && int.TryParse(args[0], out var v) ? v : 5;
        Console.WriteLine($"[DebugTarget] start, n={n}");
        Work(n);
        // 异常场景：args[1] == "throw" 时抛异常（供异常断点测试）
        if (args.Length > 1 && args[1] == "throw") { ThrowIfZero(0); }
        Console.WriteLine("[DebugTarget] done");
    }
}
'@
    Set-Content -Path (Join-Path $tmp "DebugTarget.cs") -Value $dbgSrc -Encoding UTF8

    $dbgCsproj = @"
<Project Sdk="Microsoft.NET.Sdk">
  <PropertyGroup>
    <TargetFramework>$Tfm</TargetFramework>
    <OutputType>Exe</OutputType>
    <AssemblyName>DebugTarget</AssemblyName>
    <EnableDefaultCompileItems>false</EnableDefaultCompileItems>
    <ImplicitUsings>disable</ImplicitUsings>
    <Nullable>disable</Nullable>
  </PropertyGroup>
  <ItemGroup>
    <Compile Include="DebugTarget.cs" />
  </ItemGroup>
</Project>
"@
    Set-Content -Path (Join-Path $tmp "DebugTarget.csproj") -Value $dbgCsproj -Encoding UTF8

    dotnet build (Join-Path $tmp "DebugTarget.csproj") -c Release --nologo -v q | Out-Null
    if ($LASTEXITCODE -ne 0) { throw "dotnet build (DebugTarget) failed, exit code $LASTEXITCODE" }

    $dbgExe = Join-Path $tmp "bin\Release\$Tfm\DebugTarget.exe"
    $dbgTarget = Join-Path $OutDir "DebugTarget.exe"
    Copy-Item $dbgExe $dbgTarget -Force
    Write-Host "Generated $dbgTarget"
    # DebugTarget 自包含，但 .NET 10 框架依赖运行仍需 runtimeconfig.json —— 一并复制
    Copy-Item (Join-Path $tmp "bin\Release\$Tfm\DebugTarget.runtimeconfig.json") (Join-Path $OutDir "DebugTarget.runtimeconfig.json") -Force
```

> 注意 `$dbgSrc` 是 here-string 需在脚本 UTF-16 编码内正确嵌入；保持与现有 `$sb.AppendLine`/`@"..."@` 风格一致。生成后 `DebugTarget.exe` + `.runtimeconfig.json` 落到 `tests/TestData/`（两者 git 忽略——见 Step 2）。

```csharp
namespace DotNetDebugger.Engine.Tests;

/// <summary>Engine 测试访问 tests/TestData/DebugTarget.exe 的路径解析。</summary>
internal static class TestPaths
{
    /// <summary>从测试 CWD 上溯仓库根（含 DotNetDebuggerMcp.slnx）拼 tests/TestData/DebugTarget.exe。</summary>
    public static string DebugTargetExe { get; } = Locate("tests", "TestData", "DebugTarget.exe");

    private static string Locate(params string[] segments)
    {
        var dir = new DirectoryInfo(AppContext.BaseDirectory);
        while (dir is not null)
        {
            if (File.Exists(Path.Combine(dir.FullName, "DotNetDebuggerMcp.slnx"))) break;
            dir = dir.Parent;
        }
        if (dir is null) throw new DirectoryNotFoundException("未找到仓库根目录（缺少 DotNetDebuggerMcp.slnx）");
        return Path.Combine([dir.FullName, .. segments]);
    }
}
```

```csharp
        var targetExe = TestPaths.DebugTargetExe;
        Assert.True(File.Exists(targetExe), $"DebugTarget.exe 不存在，请先运行 generate-testdata.ps1：{targetExe}");

        // 先启动目标进程（正常启动，再 attach）
        var psi = new ProcessStartInfo(targetExe, "2")
        {
            UseShellExecute = false,
            RedirectStandardOutput = true,
        };
        using var target = Process.Start(psi)!;
        // 等待目标进入 Main 稳定区（避免 attach 太早）
        await Task.Delay(500);
        Assert.False(target.HasExited, "DebugTarget 提前退出");

        var sawCreate = new TaskCompletionSource<bool>(TaskCreationOptions.RunContinuationsAsynchronously);
        var sawExit = new TaskCompletionSource<bool>(TaskCreationOptions.RunContinuationsAsynchronously);

        // 调试器工作必须在 MTA 线程（ClrDebug 硬性要求）
        var mtaThread = new Thread(() =>
        {
            try
            {
                // 1. 加载 dbgshim：优先从测试输出目录（Microsoft.Diagnostics.DbgShim 包随引用复制）
                var dbgShimDll = FindDbgShimPath();
                var hModule = NativeLibrary.Load(dbgShimDll);
                var dbgshim = new DbgShim(hModule);

                // 2. 附加：拿 CLR 版本串 → 建 ICorDebug
                var clrs = dbgshim.EnumerateCLRs(target.Id);
                Assert.True(clrs.Items.Length > 0, "目标进程未加载 CLR（可能启动太早或非 .NET 进程）");
                var clr = clrs.Items[0];
                var version = dbgshim.CreateVersionStringFromModule(target.Id, clr.Path);
                var corDebug = dbgshim.CreateDebuggingInterfaceFromVersionEx(
                    CorDebugInterfaceVersion.CorDebugVersion_4_0, version);

                // 3. 回调 → 事件泵
                var cb = new CorDebugManagedCallback();
                cb.OnCreateProcess += (_, _) => { sawCreate.TrySetResult(true); };
                cb.OnExitProcess += (_, e) =>
                {
                    sawExit.TrySetResult(true);
                    // ExitProcess 后不必 Continue
                };
                // 其它事件一律 Continue（否则进程停死）
                cb.OnAnyEvent += (_, e) =>
                {
                    if (!sawExit.Task.IsCompleted) { try { e.Controller.Continue(false); } catch { /* 已退出 */ } }
                };

                corDebug.Initialize();
                corDebug.SetManagedHandler(cb);
                corDebug.DebugActiveProcess(target.Id, win32Attach: false);
                dbgshim.CloseCLREnumeration(clrs);
            }
            catch (Exception ex)
            {
                sawCreate.TrySetException(ex);
                sawExit.TrySetException(ex);
            }
        });
        mtaThread.SetApartmentState(ApartmentState.MTA);
        mtaThread.Start();

        // 等待 CreateProcess 回调 + 目标自然退出（n=2 约 20ms 后 done → exit）
        var create = await sawCreate.Task.WaitAsync(TimeSpan.FromSeconds(15));
        Assert.True(create, "未收到 CreateProcess 回调");
        target.WaitForExit(10000);
        var exit = await sawExit.Task.WaitAsync(TimeSpan.FromSeconds(15));
        Assert.True(exit, "未收到 ExitProcess 回调");
        Assert.True(target.HasExited);
    }

    /// <summary>
    /// 在测试输出目录找随 Microsoft.Diagnostics.DbgShim 包复制的 dbgshim.dll
    /// （RID 子包结构 runtimes/win-x64/native/dbgshim.dll）。
    /// </summary>
    private static string FindDbgShimPath()
    {
        var baseDir = AppContext.BaseDirectory;
        var candidates = new[]
        {
            Path.Combine(baseDir, "runtimes", "win-x64", "native", "dbgshim.dll"),
            Path.Combine(baseDir, "dbgshim.dll"),
        };
        foreach (var c in candidates) if (File.Exists(c)) return c;
        throw new FileNotFoundException($"未找到 dbgshim.dll（搜索 {string.Join(", ", candidates)}）；请确认 Microsoft.Diagnostics.DbgShim 包已随测试复制");
    }
}
```

```csharp
using System.Threading.Channels;

namespace DotNetDebugger.Engine.Engine;

/// <summary>
/// 命令串行化队列：外部线程把命令投进来，调试线程逐个执行（spec §5 命令队列纪律）。
/// 每条命令带 TaskCompletionSource，执行结果回传调用方。
/// </summary>
public sealed class DebugCommandQueue : IDisposable
{
    private sealed record Command(Func<Task> Body, TaskCompletionSource Completion);

    private readonly Channel<Command> _channel = Channel.CreateUnbounded<Command>(
        new UnboundedChannelOptions { SingleReader = true, SingleWriter = false });
    private readonly Task _pump;

    public DebugCommandQueue()
    {
        _pump = Task.Run(async () =>
        {
            await foreach (var cmd in _channel.Reader.ReadAllAsync())
            {
                try { await cmd.Body(); cmd.Completion.TrySetResult(); }
                catch (Exception ex) { cmd.Completion.TrySetException(ex); }
            }
        });
    }

    /// <summary>投递命令并等待执行完成（在调试线程上执行 body）。</summary>
    public Task PostAsync(Func<Task> body, CancellationToken ct = default)
    {
        var completion = new TaskCompletionSource(TaskCreationOptions.RunContinuationsAsynchronously);
        if (!_channel.Writer.TryWrite(new Command(body, completion)))
        {
            completion.TrySetException(new InvalidOperationException("命令队列已关闭"));
        }
        return completion.Task.WaitAsync(ct);
    }

    /// <summary>投递同步命令（包装为 Task）。</summary>
    public Task PostAsync(Action body, CancellationToken ct = default)
        => PostAsync(() => { body(); return Task.CompletedTask; }, ct);

    public void Dispose() => _channel.Writer.TryComplete();
}
```

```csharp
using ClrDebug;

namespace DotNetDebugger.Engine.Engine;

/// <summary>结果：引导产物（CorDebug + 目标进程信息）。</summary>
public sealed record BootstrapResult(CorDebug CorDebug, int ProcessId);

/// <summary>
/// 手动引导序列（API 参考 §7 Manual 模式）：
/// ① CreateProcessForLaunch(bSuspend) 或直接用现有进程
/// ② attach 既有进程：EnumerateCLRs → CreateVersionStringFromModule → CreateDebuggingInterfaceFromVersionEx
///    → Initialize → SetManagedHandler → DebugActiveProcess
/// ③ launch 新进程：CreateProcessForLaunch(suspend) → GetStartupNotificationEvent → ResumeProcess
///    → 等 CLR 就绪 → EnumerateCLRs → ... → DebugActiveProcess → CloseResumeHandle
/// </summary>
public static class CorDebugBootstrap
{
    /// <summary>附加到已运行进程。</summary>
    public static BootstrapResult Attach(DbgShim dbgshim, int pid, ICorDebugManagedCallback handler)
    {
        var clrs = dbgshim.EnumerateCLRs(pid);
        if (clrs.Items.Length == 0)
            throw new InvalidOperationException($"目标进程 {pid} 未加载 .NET CLR（可能启动过早或非 .NET 进程）");
        var clr = clrs.Items[0];
        var version = dbgshim.CreateVersionStringFromModule(pid, clr.Path);
        var corDebug = dbgshim.CreateDebuggingInterfaceFromVersionEx(CorDebugInterfaceVersion.CorDebugVersion_4_0, version);
        try
        {
            corDebug.Initialize();
            corDebug.SetManagedHandler(handler);
            corDebug.DebugActiveProcess(pid, win32Attach: false);
            return new BootstrapResult(corDebug, pid);
        }
        finally
        {
            dbgshim.CloseCLREnumeration(clrs);
        }
    }

    /// <summary>以挂起方式启动新进程并附加（早期断点能力）。</summary>
    public static BootstrapResult Launch(DbgShim dbgshim, string commandLine, ICorDebugManagedCallback handler,
        int timeoutMs = 15000, string? workingDirectory = null)
    {
        var proc = dbgshim.CreateProcessForLaunch(commandLine, bSuspendProcess: true,
            lpCurrentDirectory: workingDirectory ?? Directory.GetCurrentDirectory());
        try
        {
            var ready = dbgshim.GetStartupNotificationEvent(proc.ProcessId);
            dbgshim.ResumeProcess(proc.ResumeHandle);
            // 等 CLR 启动通知（可超时）
            var started = NativeMethods.WaitForSingleObject(ready, timeoutMs);
            if (started != 0)
                throw new TimeoutException($"等待目标进程 {proc.ProcessId} CLR 启动超时（{timeoutMs}ms）");

            var clrs = dbgshim.EnumerateCLRs(proc.ProcessId);
            if (clrs.Items.Length == 0)
                throw new InvalidOperationException($"目标进程 {proc.ProcessId} 未加载 .NET CLR");
            var clr = clrs.Items[0];
            var version = dbgshim.CreateVersionStringFromModule(proc.ProcessId, clr.Path);
            var corDebug = dbgshim.CreateDebuggingInterfaceFromVersionEx(CorDebugInterfaceVersion.CorDebugVersion_4_0, version);
            corDebug.Initialize();
            corDebug.SetManagedHandler(handler);
            corDebug.DebugActiveProcess(proc.ProcessId, win32Attach: false);
            dbgshim.CloseCLREnumeration(clrs);

            // 放行 CLR 继续启动（coreclr 已加载完成，可设早期断点后再 SetEvent）
            NativeMethods.SetEvent(clr.Handle);
            return new BootstrapResult(corDebug, proc.ProcessId);
        }
        finally
        {
            dbgshim.CloseResumeHandle(proc.ResumeHandle);
        }
    }
}

/// <summary>dbgshim 引导用到的少量 Win32（WaitForSingleObject/SetEvent）。</summary>
internal static class NativeMethods
{
    [System.Runtime.InteropServices.DllImport("kernel32.dll", SetLastError = true)]
    public static extern int WaitForSingleObject(IntPtr hHandle, int dwMilliseconds);

    [System.Runtime.InteropServices.DllImport("kernel32.dll", SetLastError = true)]
    public static extern bool SetEvent(IntPtr hEvent);
}
```

```csharp
using DotNetDebugger.Engine.Engine;

namespace DotNetDebugger.Engine;

/// <summary>
/// 一个被调试目标的会话（v1 单活动会话；spec §4.1）。外部 API：Launch/Attach/Disconnect/Dispose +
/// 断点/执行控制/状态读取；事件经 <see cref="Events"/>（Channel 异步序列）订阅。

    private long _sequence;

    private readonly DebugEngineCore _core;
    private readonly Channel<DebugEvent> _eventChannel = Channel.CreateUnbounded<DebugEvent>(
        new UnboundedChannelOptions { SingleReader = true, SingleWriter = false });

    /// <summary>启动新进程并附加。</summary>
    public static Task<DebugSession> LaunchAsync(string commandLine, int timeoutMs = 15000, string? workingDirectory = null,

        => CreateAsync(core => core.LaunchAsync(commandLine, timeoutMs, workingDirectory, ct), ct);

    }
```

`src/DotNetDebugger.Engine/Engine/DebugEngineCore.cs`:
```csharp
using System.Threading.Channels;
using ClrDebug;
using DotNetDebugger.Engine.Models;

namespace DotNetDebugger.Engine.Engine;

/// <summary>
/// 引擎核心：专用 MTA 线程 + 引导 + CorDebugManagedCallback 接线 + 命令队列 + DebugEvent 发布。
/// 所有 ICorDebug 调用只发生在此线程/回调线程（spec §5）。对外命令经命令队列串行化。
/// </summary>
public sealed class DebugEngineCore : IAsyncDisposable
{
    private readonly object _gate = new();
    private readonly DebugCommandQueue _commandQueue = new();
    private readonly Channel<DebugEvent> _outbound = Channel.CreateUnbounded<DebugEvent>();
    private Action<DebugEvent>? _sink;

    private CorDebug? _corDebug;
    private CorDebugProcess? _process;
    private bool _running;

    /// <summary>启动新进程并附加（在 MTA 线程执行引导）。</summary>
    public Task LaunchAsync(string commandLine, int timeoutMs, string? workingDirectory, CancellationToken ct)
        => RunOnDebugThreadAsync(() =>
        {
            if (_running) throw new InvalidOperationException("会话已在运行");
            _running = true;

            var dbgshim = DbgShimLoader.Load(targetRuntimeDir: null);
            var cb = new CorDebugManagedCallback();
            var handler = new CallbackHandler(this, cb);
            var result = CorDebugBootstrap.Launch(dbgshim, commandLine, cb, timeoutMs, workingDirectory);
            _corDebug = result.CorDebug;
            _process = result.CorDebug.GetProcess(result.ProcessId);
            PublishState(DebugSessionState.Launching, "launched");
        }, ct);

    /// <summary>附加到已运行进程。</summary>
    public Task AttachAsync(int processId, CancellationToken ct)
        => RunOnDebugThreadAsync(() =>
        {
            if (_running) throw new InvalidOperationException("会话已在运行");
            _running = true;

            var dbgshim = DbgShimLoader.Load(targetRuntimeDir: null);
            var cb = new CorDebugManagedCallback();
            var handler = new CallbackHandler(this, cb);
            var result = CorDebugBootstrap.Attach(dbgshim, processId, cb);
            _corDebug = result.CorDebug;
            _process = result.CorDebug.GetProcess(result.ProcessId);
            PublishState(DebugSessionState.Attaching, "attached");
        }, ct);

    /// <summary>继续执行（目标停在断点/步后）。</summary>
    public Task ContinueAsync(CancellationToken ct)
        => RunOnDebugThreadAsync(() =>
        {
            // Continue 必须在进程同步态由回调触发；这里经命令队列进调试线程
            var controller = CurrentController();
            controller?.Continue(false);
            PublishState(DebugSessionState.Running, "continued");
        }, ct);

    /// <summary>断开调试（detach）。</summary>
    public Task DisconnectAsync(CancellationToken ct)
        => RunOnDebugThreadAsync(() =>
        {
            try { _process?.Detach(); } catch { /* 已退出则忽略 */ }
            PublishState(DebugSessionState.Detached, "detached");
            _running = false;
        }, ct);

    /// <summary>内部：回调处理器投递状态更新。</summary>
    internal void OnStateChanged(DebugSessionState state, string? reason)
        => PublishState(state, reason);

    private CorDebugController? CurrentController() => _process as CorDebugController;

    private void PublishState(DebugSessionState state, string? reason)
        => Publish(new DebugEvent(Id, NextSeq(), DateTimeOffset.UtcNow, DebugEventKind.SessionStateChanged,
            new SessionStateChangedPayload(state, reason)));

    private void Publish(DebugEvent e)
    {
        _outbound.Writer.TryWrite(e);
        lock (_gate) _sink?.Invoke(e);
    }

    internal void AttachEventSink(Action<DebugEvent> sink)
    {
        lock (_gate) _sink = sink;
        // 回放已缓冲事件（连接前产生的）
        while (_outbound.Reader.TryRead(out var e)) sink(e);
    }

    internal void Log(string level, string message)
        => Publish(new DebugEvent(Id, NextSeq(), DateTimeOffset.UtcNow, DebugEventKind.EngineLog, new EngineLogPayload(level, message)));

    private string Id => "session";
    private long _seq;
    private long NextSeq() => Interlocked.Increment(ref _seq);

    private async Task RunOnDebugThreadAsync(Action action, CancellationToken ct)
        => await _commandQueue.PostAsync(action, ct);

    public async ValueTask DisposeAsync()
    {
        _commandQueue.Dispose();
        _outbound.Writer.TryComplete();
        await Task.CompletedTask;
    }
}
```

> 设计取舍：v1 把「回调线程」与「命令执行线程」统一——`RunOnDebugThreadAsync` 经命令队列执行，但**引导本身需要在 MTA 线程**。此骨架为简化假设调试线程即 MTA；实际实现时 DebugEngineCore 应自持一个 MTA 线程并让命令队列 pump 运行于其上（Task 执行期按 spike 结果校正，勿机械照抄）。断点/单步的「在同步态执行」约束由回调处理器直接驱动（见 Task 5/6）。

```csharp
using ClrDebug;
using DotNetDebugger.Engine.Models;

namespace DotNetDebugger.Engine.Engine;

/// <summary>
/// CorDebugManagedCallback 事件 → 引擎状态机 + DebugEvent。每个回调处理完必须 Continue（spec §5）；
/// ExitProcess 后不 Continue。
/// </summary>
public sealed class CallbackHandler
{
    private readonly DebugEngineCore _core;

    public CallbackHandler(DebugEngineCore core, CorDebugManagedCallback cb)
    {
        _core = core;
        cb.OnCreateProcess += (_, e) => { _core.Log("info", $"CreateProcess pid={e.Process?.ProcessId}"); };
        cb.OnExitProcess += (_, _) => _core.OnStateChanged(DebugSessionState.Exited, "process exited");
        cb.OnLoadModule += (_, e) => { _core.Log("info", $"LoadModule {e.Module?.Name}"); };
        cb.OnException += (_, _) => { /* Task 7 异常断点实现 */ };
```

```csharp
using ClrDebug;
using DotNetDebugger.Engine.Models;

namespace DotNetDebugger.Engine.Engine;

/// <summary>
/// 断点管理：登记 DebugBreakpoint 并绑定到目标进程模块/函数/IL。模块加载事件时登记模块供按名查找
/// （v1：断点需模块已加载才能设，未加载抛中文提示）。
/// </summary>
public sealed class BreakpointManager
{
    private readonly List<DebugBreakpoint> _breakpoints = new();
    private readonly Dictionary<string, CorDebugModule> _modules = new(StringComparer.OrdinalIgnoreCase);
    private int _nextId = 1;

    /// <summary>模块加载时登记（供按名查找）。</summary>
    public void TrackModule(CorDebugModule module)
    {
        try { _modules[module.Name] = module; }
        catch { /* 名称获取失败忽略 */ }
    }

    public IReadOnlyList<DebugBreakpoint> Breakpoints => _breakpoints;

    /// <summary>登记并绑定断点。模块未加载/方法无 IL 抛中文 InvalidOperationException。</summary>
    public DebugBreakpoint Add(string moduleName, int methodToken, int ilOffset)
    {
        if (!_modules.TryGetValue(moduleName, out var module))
        {
            throw new InvalidOperationException(
                $"模块 {moduleName} 尚未加载（断点需模块加载后才能设置；先运行到该模块加载，或用反编译工具确认模块名）");
        }

        var bp = new DebugBreakpoint(_nextId++, moduleName, methodToken, ilOffset);
        CorDebugFunction fn;
        try
        {
            fn = module.GetFunctionFromToken(new mdMethodDef((uint)methodToken));
        }
        catch (Exception ex)
        {
            throw new InvalidOperationException($"方法 {methodToken:x8} 定位失败（{ex.Message}）；token 应为 0x06 开头的 mdMethodDef", ex);
        }
        var il = fn.ILCode
            ?? throw new InvalidOperationException($"方法 {methodToken:x8} 无 IL 代码（可能未 JIT 或非 IL 方法，先运行到该方法再设断点）");
        var runtimeBp = il.CreateBreakpoint(ilOffset);
        runtimeBp.Activate(true); // 关键：创建后必须 Activate 才生效（源码核对 A.2）
        bp.RuntimeBreakpoint = runtimeBp;
        _breakpoints.Add(bp);
        return bp;
    }

    public bool Remove(int id)
    {
        var bp = _breakpoints.FirstOrDefault(b => b.Id == id);
        if (bp is null) return false;
        bp.RuntimeBreakpoint?.Activate(false);
        _breakpoints.Remove(bp);
        return true;
    }

    public void Clear()
    {
        foreach (var bp in _breakpoints) bp.RuntimeBreakpoint?.Activate(false);
        _breakpoints.Clear();
    }

    /// <summary>回调命中时匹配是哪个登记的断点（按 RuntimeBreakpoint 引用相等，最稳）。</summary>
    public DebugBreakpoint? Match(CorDebugFunctionBreakpoint hit)
        => _breakpoints.FirstOrDefault(b => ReferenceEquals(b.RuntimeBreakpoint, hit));
}
```

关键：把「无条件 Continue」改为状态机控制。用一个 `_holdContinue` 标志——停点事件（Breakpoint 命中）置位并发布事件，OnAnyEvent 看到标志则跳过 Continue；外部 `ContinueAsync` 清标志并调 Controller.Continue。

`src/DotNetDebugger.Engine/Engine/CallbackHandler.cs` 重构为:
```csharp
using ClrDebug;
using DotNetDebugger.Engine.Models;

namespace DotNetDebugger.Engine.Engine;

/// <summary>
/// CorDebugManagedCallback 事件 → 引擎状态机 + DebugEvent。停点事件（断点/步完成/异常）不立即
/// Continue，发布事件后挂起（holdContinue 置位），等外部 Continue 命令恢复。
/// </summary>
public sealed class CallbackHandler
{
    private readonly DebugEngineCore _core;
    private readonly BreakpointManager _breakpoints;

    // 停点挂起标志：置位时 OnAnyEvent 不 Continue（进程保持停止，等外部 continue）
    private volatile bool _holdContinue;

    public CallbackHandler(DebugEngineCore core, CorDebugManagedCallback cb, BreakpointManager breakpoints)
    {
        _core = core;
        _breakpoints = breakpoints;

        cb.OnCreateProcess += (_, e) => _core.Log("info", $"CreateProcess pid={e.Process?.ProcessId}");
        cb.OnLoadModule += (_, e) =>
        {
            if (e.Module is not null) { _breakpoints.TrackModule(e.Module); _core.Log("info", $"LoadModule {e.Module.Name}"); }
        };
        cb.OnExitProcess += (_, _) => _core.OnStateChanged(DebugSessionState.Exited, "process exited");
        cb.OnBreakpoint += OnBreakpoint;
        cb.OnAnyEvent += (_, e) =>
        {
            if (_holdContinue) return;          // 停点挂起：等外部 continue
            if (e.Kind == CorDebugManagedCallbackKind.ExitProcess) return; // 退出后不 Continue
            try { e.Controller.Continue(false); }
            catch { /* 进程已退出等 */ }
        };
    }

    private void OnBreakpoint(object? sender, BreakpointCorDebugManagedCallbackEventArgs e)
    {
        if (e.Breakpoint is not CorDebugFunctionBreakpoint fbp) return;
        var matched = _breakpoints.Match(fbp);
        if (matched is null) return; // 非登记的断点，继续跑（不 hold）

        // 读栈顶帧 → 发布 BreakpointHit → hold（不 Continue，等外部命令）
        var top = _core.ReadTopFrame(e.Thread);
        _core.PublishBreakpointHit(matched.Id, e.Thread.Id, top);
        _core.OnStateChanged(DebugSessionState.Stopped, $"breakpoint {matched.Id}");
        _holdContinue = true;
    }

    /// <summary>外部 Continue 命令调用：清 hold 并继续（由 DebugEngineCore 在调试线程调）。</summary>
    public void ReleaseContinue()
    {
        _holdContinue = false;
    }
}
```
> `CorDebugManagedCallbackKind.ExitProcess` 需确认枚举成员名（回调 Kind 枚举，源码核对 A.2 表——实现时按实际枚举名校正）。

```csharp
/// <summary>线程 → 调用栈帧列表（FrameLocation + 可选类型/方法名）。进程同步态调用。</summary>
public static class StackWalker
{
    public static IReadOnlyList<DebugStackFrame> GetFrames(CorDebugThread thread)
    {
        var frames = new List<DebugStackFrame>();
        var walk = thread.CreateStackWalk();
        var index = 0;
        while (true)
        {
            CorDebugFrame? frame;
            var hr = walk.TryGetFrame(out frame);
            if (hr != HRESULT.S_OK) break; // S_FALSE=原生帧/结束
            if (frame is CorDebugILFrame ilf)
            {
                try
                {
                    var module = ilf.Function?.Module?.Name ?? "<unknown>";
                    var token = (int)ilf.FunctionToken.Value;
                    var ip = ilf.IP.pnOffset;
                    frames.Add(new DebugStackFrame(new FrameLocation(module, token, ip), index++)
                    {
                        TypeName = ilf.Function?.Class?.Name,
                        MethodName = ilf.Function?.Token.ToString(),
                    });
                }
                catch { /* 帧读取失败跳过 */ }
            }
            var nextHr = walk.TryNext();
            if (nextHr != HRESULT.S_OK) break;
        }
        return frames;
    }
}
```
> HRESULT 常量名（S_OK 等）与 TryGetFrame 语义以 ClrDebug 实际为准（实现时对照源码）。

```csharp
using System.Runtime.InteropServices;
using ClrDebug;
using DotNetDebugger.Engine.Models;

namespace DotNetDebugger.Engine.Diagnostics;

/// <summary>
/// CorDebugValue → DebugValue 树。v1 覆盖：primitive/string 标量；引用对象展开首层字段（深度 1）；
/// 数组/复杂结构降级摘要。进程同步态调用。
/// </summary>
public static class ValueReader
{
    public static DebugValue Read(CorDebugValue value, int depth = 0)
    {
        try
        {
            switch (value)
            {
                case CorDebugStringValue s:
                    return DebugValue.Scalar($"\"{s.GetString(s.Length)}\"");
                case CorDebugGenericValue g:
                    return DebugValue.Scalar(ReadGeneric(g));
                case CorDebugReferenceValue r when r.IsNull:
                    return DebugValue.Scalar("null");
                case CorDebugReferenceValue r when depth == 0:
                    return ReadObject(r.Dereference(), depth + 1);
                case CorDebugArrayValue a:
                    return DebugValue.Summary("array", $"[{a.Rank} 维数组]");
                default:
                    return DebugValue.Summary("value", value.ToString() ?? "<value>");
            }
        }
        catch (Exception ex)
        {
            return DebugValue.Summary("error", $"<读取失败:{ex.Message}>");
        }
    }

    private static DebugValue ReadObject(CorDebugValue? obj, int depth)
    {
        if (obj is not CorDebugObjectValue ov)
            return DebugValue.Summary("object", obj?.ToString() ?? "null");

        var fields = new List<DebugVariable>();
        // 首层字段枚举：经 ov.Class 拿字段元数据 + ov.GetFieldValue —— 精确 API 以 ClrDebug 源码为准
        // （CorDebugClass.Fields / CorDebugObjectValue 字段读取，sharpdbg/dnSpy 有参考实现）
        return DebugValue.Object(ov.Class?.Name ?? "<object>", fields);
    }

    private static string ReadGeneric(CorDebugGenericValue g)
    {
        var size = g.Size;
        var buf = Marshal.AllocHGlobal(size);
        try
        {
            g.GetValue(buf);
            return size switch
            {
                1 => ((byte)Marshal.ReadByte(buf)).ToString(),
                4 => Marshal.ReadInt32(buf).ToString(),
                8 => Marshal.ReadInt64(buf).ToString(),
                _ => $"<{size}字节>",
            };
        }
        finally { Marshal.FreeHGlobal(buf); }
    }
}
```
> 注：`CorDebugObjectValue` 字段枚举的精确 API（Class.Fields → GetFieldValue）需对照 ClrDebug 源码 + sharpdbg 参考实现补全。v1「简单对象首层字段」范围：public/私有字段均读，标量直接渲染、嵌套对象摘要。

```csharp
using DotNetDebugger.Engine;
using DotNetDebugger.Engine.Models;

namespace DotNetDebuggerMcp.DebugCli;

/// <summary>
/// CLI -dbg 一次性调试场景：launch/attach → 下断点 → continue → 命中后打印栈与变量 → 恢复 → 退出。
/// 结果写 stdout（CLI 模式，非 MCP）；错误/日志走 stderr。
/// </summary>
public static class DebugCliRunner
{
    public static async Task<int> RunAsync(string exePath, int methodToken, int ilOffset,
        string? workingDirectory, int timeoutSeconds, CancellationToken ct)
    {
        try
        {
            await using var session = await DebugSession.LaunchAsync(exePath, timeoutSeconds * 1000, workingDirectory, ct);
            Console.WriteLine($"已启动并附加: {exePath}");

            var events = new List<DebugEvent>();
            var readerTask = ConsumeAsync(session.Events, events);
            await Task.Delay(100);

            var bp = await session.SetBreakpointAsync(
                System.IO.Path.GetFileNameWithoutExtension(exePath) + ".dll", methodToken, ilOffset);
            Console.WriteLine($"断点已设: [{bp.Id}] token=0x{methodToken:x8} offset={ilOffset}");

            await session.ContinueAsync();

            var deadline = DateTime.UtcNow.AddSeconds(timeoutSeconds);
            while (DateTime.UtcNow < deadline && !events.Any(e => e.Kind == DebugEventKind.BreakpointHit))
                await Task.Delay(100);

            var hit = events.LastOrDefault(e => e.Kind == DebugEventKind.BreakpointHit);
            if (hit is null)
            {
                Console.Error.WriteLine($"超时未命中断点（{timeoutSeconds}s）");
                return 1;
            }
            var top = (hit.Payload as BreakpointHitPayload)?.TopFrame;
            Console.WriteLine($"断点命中: {top}");

            // 读当前停住线程的栈与变量
            var threads = await session.GetThreadsAsync(ct);
            foreach (var t in threads.Take(1))
            {
                var frames = await session.GetStackFramesAsync(t.ThreadId, ct);
                Console.WriteLine("调用栈:");
                foreach (var f in frames.Take(8))
                    Console.WriteLine($"  {f.FrameIndex}: {f.Location}");
                var vars = await session.GetVariablesAsync(t.ThreadId, ct);
                Console.WriteLine("局部变量/参数:");
                foreach (var (scope, list) in vars)
                foreach (var v in list)
                    Console.WriteLine($"  [{scope}] {v.Name ?? $"slot{v.Slot}"} = {v.Value.Display}");
            }

            await session.ContinueAsync();
            Console.WriteLine("已恢复执行，等待进程退出...");
            await Task.Delay(2000);
            Console.WriteLine("完成");
            return 0;
        }
        catch (Exception ex)
        {
            Console.Error.WriteLine($"调试失败: {ex.Message}");
            return 1;
        }
    }

    private static async Task ConsumeAsync(IAsyncEnumerable<DebugEvent> src, List<DebugEvent> into)
    {
        await foreach (var e in src) { lock (into) into.Add(e); }
    }
}
```
